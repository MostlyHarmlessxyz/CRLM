在 Codex 中打开本项目根目录，选择你要使用的模型；如界面提供 Plan 模式，先由你切换到该模式，再粘贴下方正文。提示词不能替你切换界面模式，也不改变系统、开发者、工具或目录权限。此提示词只授权只读调查和制定计划，不授权开始执行项目。

## 一、研究目标与材料优先级

在当前有效的系统、开发者、用户及工作目录指令约束内，项目研究意图以 `docs/source_brief/说明.md` 为最高依据：找出原发灶与肝转移灶之间跨患者、跨独立来源可复现的免疫细胞状态及分子程序，并检验器官背景；分类是筛选和检验信息的中间工具。保留分类主干，但不以 AUROC 替代生物学复现，也不将已取得组织的分类写成未来转移风险预测。

按以下顺序读取实际存在的文件；不要根据本提示词假定文件已经齐全：

1. 根目录及涉及子目录的 `AGENTS.md`，以及 `README.md`。
2. `docs/source_brief/说明.md`、其他原始项目材料。
3. `docs/CRLM_Research_Plan.md`，尤其数据角色、输入能力、患者统计、模型比较、候选冻结、实验边界及附录。
4. `docs/IMPLEMENTATION_PLAN.md`、`configs/project.json`、`docs/COMPUTE_GUIDE.md`（若存在）。
5. `references/reading_manifest.csv` 及其中列出的关键原始论文/官方补充；区分本地全文、摘要、已核实引用、访问受限与待读。仅凭摘要不要声称已复现算法。缺少 PhenoAligner 等正式全文时登记缺口，不自行补写作者方法。
6. `starter/` 的 README、已有脚本、templates、audit_data、literature_seeds、evidence 与历史检查结果，以及项目当前源码/任务状态。

现有报告与审计是研究起点，原始来源可以纠正其中事实；发现矛盾时列出位置、证据与处理建议，不静默选择最方便的版本。不要重新展开无边界的文献综述。

## 二、本轮允许的工作与能力核查

本轮可以读取文件、检查代码、查看现有输出和 Git 状态、进行不产生文件的必要事实计算，以及使用当前工具允许的只读查询。先确认工作目录、现有文件、可调用工具及实际模式。

本轮不写计划文件、不修改配置或代码、不安装依赖、不下载数据/模型权重、不运行训练或会产生输出的自检。`selfcheck.py`、`mil_selfcheck.py`、`registered_tests_selfcheck.py` 会生成文件或临时产物；现在只读其代码和历史结果，将重新运行列入 M0。不要把“先运行一遍再计划”混入只读阶段。无需为了完成计划初始化仓库或创建任何产物目录。

已知本地硬件是 **i5-13400、64 GB RAM、400 GB 空闲 SSD、Intel Arc A750**。操作系统、驱动、Python/R、当前依赖及 GPU 软件后端尚待核实。通过可用的只读系统信息和已安装包信息检查 CPU/CUDA/XPU 的实际条件；不要假定 A750 可直接运行要求 CUDA 的仓库，也不要仅因没有 NVIDIA 工具而断言没有 GPU。需要安装或实际负载测试才能确认的能力，放入执行阶段。

M0–M1 默认本地 CPU 起步，GPU 未落实不构成阻塞。后续是否使用 AutoDL、Colab 或其他计算环境，由小规模 profile、后端兼容性、峰值内存/显存、磁盘占用及运行时长决定；不编造具体云价格、完成时长或显存保证。

## 三、必须核实并保留的研究约束

- **完成状态：** 当前 106 项检查是旧起步包的合成/逻辑验证。`artifacts/handoff/` 只记录本次骨架交付检查，不能算正式 M0 已完成。真实细胞 QC、统一注释、程序评分、scGPT 编码和真实模型比较仍待开展；后续只能按实际文件和日志更新状态。
- **数据角色：** 主路线用 GSE245552 发现/开发，GSE164522 做冻结后的四组织外部复现；GSE178318、GSE203608 为预登记的次要方向来源。GSE225857 身份映射未解决时不能进入配对主检验。受控、未获得或仅核元数据的资源不能计入落实的验证 N。
- **真实独立单位：** 245 的历史审计口径为 39 个样本、16 位公开患者、13 个完整 PT–LM 患者对，Pt18 有四组织；这是导入前口径，不能承诺 QC 后仍全部可用。患者、病灶、文库、细胞与技术重复分别记账；全部组织/病灶跟随患者分折。
- **尺度与基因范围：** 245 的作者交付整数 counts 不等于完整未经筛选矩阵；肿瘤与邻近组织的 feature 集合不同，缺 MT 基因时不能把 `pct_mt=0` 当作高质量。164 是作者处理后连续表达，不能反变换四舍五入冒充原始 UMI。区分未测、低覆盖、缺失与实测零。
- **暴露与独立性：** 164 的部分已发表亚群比例已在研究审计中查看，保留暴露记录，不称完全盲验证。不能为了调模型或挑候选提前读取新的外部程序效应；同一患者被复用发表不增加独立 N。
- **模型公平性：** 后续固定 scGPT 编码器及权重/词表/预训练来源版本，明确缺基因与截断处理；PCA/HVG/标准化/特征选择/新程序学习/早停都在合法训练范围内。计划包含简单程序/组成基线、PCA 均值、PCA 注意力、scGPT 均值、scGPT 注意力，以及有条件接入的 HA/CTA、MixMIL 等直接前作。使用相同患者分割、谱系、信息和预定调参预算，不能把现有透明线性 attention 原型称为官方模型完整复现。
- **证据终点：** 报告患者内 `D_T`、`D_N`、同一四组织共同子集的 `I`，区分组成与状态；这些是观察性估计。注意力不等于带符号贡献，RNA 呈递/细胞毒分数不等于真实功能。SPP1–CXCL9/IFN 等已有机制不能预先包装成创新。

## 四、请形成的分阶段计划

先对齐 `docs/IMPLEMENTATION_PLAN.md` 与实际配置；若阶段定义冲突，给出明确建议和理由。按以下范围细化，不在本轮执行：

| 阶段 | 应解决的问题 |
|---|---|
| M0 | 环境与资源、材料和来源清单、manifest 口径、旧起步包自检复核、未解决事项 |
| M1 | 245 一对 PT–LM 加 Pt18 四组织的最小真实稀疏导入、QC 能力判断、初级谱系覆盖；样本/患者重叠去重 |
| M2 | 全部发现数据的统一处理、注释、谱系覆盖及有效患者 N |
| M3 | 发现集的患者级程序与组成/状态分析、有限候选筛选 |
| M4 | 公平基线、冻结表示与有限 MIL 比较及归因稳定性 |
| M5 | 候选、方向、基因范围、评分、检验家族与验证规则冻结 |
| M6 | 独立来源复现、四组织背景及压力测试 |
| M7 | 实测空间支持与针对性功能验证准备 |
| M8 | 全部结果、失败分析、可复现代码和论文材料交付 |

把 M0–M1 细化到输入文件、拟执行命令/代码入口、拟新增或修改的文件、输出路径、通过标准、失败处理和完成后可以/不能声称的结论。命令仅作为计划展示，不执行。若 Pt18 自身已覆盖所选 PT–LM 对，不重复下载或多算患者。M0–M1 不训练模型、不做新外部程序效应检验，也不冻结真实生物候选。

对后续阶段明确依赖与门槛，避免把所有模型并行铺开。优先解决身份/尺度/覆盖，随后解决患者效应与简单基线，最后才评估复杂模型增量。每个阶段都有可检查的完成证据，不以“写好脚本”代替“已运行并验证真实输出”。

## 五、本轮回答格式

最终在聊天中给出一份完整计划，至少包含：

1. **当前事实与缺口：** 已读取资料、实际工作目录/环境、已有产物、历史检查与尚未完成事项；标注可追溯路径。
2. **关键决策：** 研究终点、数据角色和身份规则、尺度分支、模型比较、候选冻结、资源路线，以及每项决策的理由。
3. **M0–M1 可执行清单：** 按顺序列任务、输入、预期输出、验收和失败路径。正式产物使用项目约定目录，如 `artifacts/m0/`、`artifacts/m1/`，不覆盖交付时的历史证据。
4. **M2–M8 路线：** 阶段依赖、优先级、可中止条件和论文证据链。时间只是条件化估计；性能、生物学方向和机制不作保证。
5. **风险与停止门槛：** 身份/尺度不清、无共同基因或细胞支持、患者 N 过少、资源 profile 不可行、候选不稳定、外部复现失败时分别怎么处理。
6. **明确未完成清单：** 不把论文阅读、已有合成 demo、单对导入、弱数值证据或未运行的代码当成全项目完成。
7. **真正阻塞的问题：** 只问会改变当前方案且无法由现有资料判断的极少数问题。其余选择给出合理默认、理由及可更改条件，继续把计划做完整。GPU 或云账户未落实不能阻止 CPU 版 M0–M1 计划。

计划交付后停在本轮边界，不声称已切换模式，不自动运行后续阶段。只有用户退出 Plan 并授权当前执行范围后，才进入相应实施。
