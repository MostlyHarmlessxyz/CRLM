# CRLM 实现与模块范围

[annotation_m1.py](annotation_m1.py) 提供真实计数上的初级谱系标记规则，由[稀疏导入入口](../../scripts/import_gse245552.py)调用。Pt18 四组织的命令、输入与结果见 [M1 报告](../../artifacts/m1/stage_report.md)。下表为后续模块的输入与输出约定。

| 拟建模块 | 必须遵守的输入/输出合同 |
|---|---|
| `ingest/` | 来源 URL/哈希、样本与细胞轴、feature 范围、稀疏数据、尺度标识；不覆盖原文件 |
| `qc/` | 分样本能力检查、不可计算指标记 NA、过滤日志；禁止缺 MT 值填 0 |
| `annotation/` | 统一层级、未知/不确定标签、患者/谱系覆盖；不假定原作者标签等于独立验证 |
| `programs/` | 固定/学习程序分开、基因映射和覆盖、样本×谱系×程序读数 |
| `representations/` | PCA 在合法训练范围内拟合；scGPT 权重/词表/前处理/截断/后端/种子及重叠审计 |
| `models/` | 相同患者分折和可比输入；先 mean/简单基线，后有限 attention/直接前作 |
| `statistics/` | 患者单位、病灶和技术重复层级；可包装已审计 starter，但不能跳过上游真实性审计 |
| `validation/` | 冻结候选、独立来源、同一四组织共同子集、完整检验家族及失败记录 |

已存在的可运行接口在 `starter/README.txt`；manifest、程序分数和嵌入 NPZ 的列/形状按该文件及 templates 对齐。不要在新包里悄悄改变同名统计量或重定义患者 N。正式代码应由当前阶段的实际输入和验收驱动，不先堆空壳函数。
