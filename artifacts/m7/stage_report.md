# M7 · 多尺度无损空间邻近审计与条件性实验准备

## 1. 公开 Xenium 空间材料（`GSE335552`）多尺度重算结论

1. **材料与 M3 同构去污染面板覆盖**：核验 3 位 CRLM 患者的 4 张 Xenium 切片（`M242T`、`M131T`、`M397T` 肝转移灶及 `M131N` 匹配邻近肝，共 646,711 个分割细胞；无配对原发结直肠切片）。经 `src/crlm/hgnc_alias_map.py` 规范化并剥离 `B19_S4_Mac_SPP1` 混入的跨谱系 T/NK 毒力基因（`GZMB`、`GNLY`、`LAT`、`IL2RG`）后，Xenium 实测 `Mac_SPP1` 髓系成员由原 `9–10/160` 修正为 **`7–8/156`（`4.5%–5.1%`）**；与 M3 完全同构的 `Core_Lipid_SAM_R` 覆盖 **`4–5/16`**（`SPP1, TREM2, LGALS3, MMP9` ± `FABP5`），驻留 `Resident_Kupffer` 覆盖 **`7–9/14`**（`MARCO, CD5L, FOLR2, TIMD4, VCAM1, CD163, C1QA` ± `CETP, LYVE1`），`Core_Chemokine_IFN_C` 覆盖 **`6/14`**（`CXCL9, CXCL10, CXCL11, STAT1, IRF1, IDO1`），`B07_Th17_TWEAK` 覆盖 **`4–5/14`**（`CCR6, CXCR6, KLRB1, RORC` ± `IL22`；未测 `IL17A`、`TNFSF12`），`UPR` 仅 **`3/107`**。[面板覆盖表](spatial_measurement_audit/measured_coverage.csv)
2. **接触边界转录本溢出救回（消除近邻接触盲删偏差）**：原实现以 `t & my` 直接删掉了 `M242T` **49.8%**（1,238/2,485）与 `M397T` **41.1%**（5,943/14,444）的候选 `CD3⁺CD8⁺` 细胞（实测 `M397T` 重叠细胞中仅 **14.6%** 为 `SPP1⁺`，远低于髓系整体的 **29.3%**）。基于核心标志物转录本优势比互斥消歧后，主分支在 `M242T` 救回 **+346** 个（`1,247 → 1,593`）、在 `M397T` 救回 **+3,236** 个（`8,501 → 11,737`）接触态 `CD8 T` 细胞，并同步保留严格零溢出分支作透明对照。[细胞支持表](spatial_measurement_audit/sample_support.csv)
3. **中尺度肿瘤巢分隔 vs 微尺度直接排斥的精确边界（`400 / 200 / 100 / 50 µm` × `EPCAM` 距离分层 × `1,000` 次独立置换）**：
   - 在 `200 µm` 全髓系主分支下，`M242T`、`M131T`、`M397T` 的 `SPP1⁺ − SPP1⁻` 最近 `CD3/CD8` 距离差分别为 **`+4.49 µm`（`p = 0.001`）**、**`+10.79 µm`（`p = 0.001`）**、**`+4.75 µm`（`p = 0.001`）**。
   - **尺度收缩与肿瘤巢混杂分解**：当方格由 `400 µm` 缩至 `50 µm` 时，`M242T`（`+9.08 → +4.49 → +2.67 → +2.44 µm`）与 `M397T`（`+13.53 → +4.75 → +1.42 → +0.77 µm`）单调大幅衰减；仅含 **31 个** `CD3/CD8` 细胞的 `M131T` 则在 `<=100 µm` 下落入置换零分布（`100 µm`: **`+3.34 µm, p = 0.203`**, 66 格；`50 µm`: **`+4.23 µm, p = 0.289`**, 仅 12 稀疏格的零分布内波动）。尤其在 T 细胞充足且 `SPP1⁺` 比例均衡（`29.3%`）的 `M397T` 中，拆分距 `EPCAM⁺` 肿瘤上皮 `<15 µm`（肿瘤巢内/近巢，`200 µm` 格 `Δ = +7.67 µm, p = 0.001`）与 `>=15 µm`（纤维血管间质带，`200 µm` 格 **`Δ = +0.71 µm, p = 0.093`**；`100 µm` 格 **`Δ = +0.44 µm, p = 0.190`**）直接证实：中尺度表观距离差主要由**`SPP1⁺` 巨噬浸润缺 T 细胞的 `EPCAM⁺` 肿瘤巢/缺氧区、而 `SPP1⁻` 髓系与 `CD8 T` 共居间质带**的微解剖分区驱动，而非间质内微尺度直接排斥（注：在 `SPP1⁺ ~89%` 且 T 细胞仅 31 个的 `M131T` `400 µm` 粗格中，子层合格格子集差异带来 `+20.26/+22.40 µm` vs 混合 `+16.37 µm` 的小样本波动）。唯一邻近肝切片 `M131N` 仅 `1.1%` 髓系为 `SPP1⁺`（2–12 格），无稳定方向。[多尺度结果详情](spatial_measurement_audit/results.md) · [完整距离与置换表](spatial_measurement_audit/local_distances.csv)
