# M7 · 多尺度无损空间邻近审计与条件性实验准备

## 1. 公开 Xenium 空间材料（`GSE335552`）多尺度重算结论

1. **材料与 `CRLM_V1.1_245_F1` 对齐去污染面板覆盖**：核验 3 位 CRLM 患者的 4 张 Xenium 切片（`M242T`、`M131T`、`M397T` 肝转移灶及 `M131N` 匹配邻近肝，共 646,711 个分割细胞；无配对原发结直肠切片）。对齐冻结 `CRLM_V1.1_245_F1`（`artifacts/m5/gene_sets/` 与 `artifacts/m3/program_definitions_draft/program_genes.csv`）并同时剥离 `B19_S4_Mac_SPP1` 混入的跨谱系 T/NK 毒力基因（`GZMB`、`GNLY`、`LAT`、`IL2RG`）及内皮污染基因 `FLT1` 后，Xenium 实测 `B19_S4_Mac_SPP1_clean` 髓系成员统一为 **`7/159`（全集 `4.4%`） / `7/157`（共享核轴 `4.5%`）**；`HALLMARK_UNFOLDED_PROTEIN_RESPONSE` 为 **`3/113`（全集） / `3/111`（共享核轴）**；预登记主候选 `Core_Lipid_SAM_R` 覆盖 **`4–5/16`**（`SPP1, TREM2, LGALS3, MMP9` ± `FABP5`），`B07_Th17_TWEAK` 覆盖 **`4–5/14`**（`CCR6, CXCR6, KLRB1, RORC` ± `IL22`；未测 `IL17A`、`TNFSF12`），`Resident_Kupffer` 覆盖 **`7–9/14`**，`Core_Chemokine_IFN_C` 覆盖 **`6/14`**。[面板覆盖表](spatial_measurement_audit/measured_coverage.csv)
2. **接触边界转录本溢出救回（消除近邻接触盲删偏差）**：原实现以 `t & my` 直接删掉了 `M242T` **49.8%**（1,238/2,485）与 `M397T` **41.1%**（5,943/14,444）的候选 `CD3⁺CD8⁺` 细胞（实测 `M397T` 重叠细胞中仅 **14.6%** 为 `SPP1⁺`，远低于髓系整体的 **29.3%**）。基于核心标志物转录本优势比互斥消歧后，主分支在 `M242T` 救回 **+346** 个（`1,247 → 1,593`）、在 `M397T` 救回 **+3,236** 个（`8,501 → 11,737`）接触态 `CD8 T` 细胞，并同步保留严格零溢出分支作透明对照。[细胞支持表](spatial_measurement_audit/sample_support.csv)
3. **多尺度衰减、双切片对称 `EPCAM` 分层与半格平移/`~EPCAM` 溢出边界（`400 / 200 / 100 / 50 µm` × `1,000` 次独立置换）**：
   - 在 `200 µm` 全髓系主分支下，`M242T`、`M131T`、`M397T` 的 `SPP1⁺ − SPP1⁻` 最近 `CD3/CD8` 距离差分别为 **`+4.49 µm`（`p = 0.001`）**、**`+10.79 µm`（`p = 0.001`）**、**`+4.75 µm`（`p = 0.001`）**；当方格由 `400 µm` 缩至 `50 µm` 时，`M242T`（`+9.08 → +4.49 → +2.67 → +2.44 µm`）与 `M397T`（`+13.53 → +4.75 → +1.42 → +0.77 µm`）均单调衰减，而仅含 **31 个** `CD3/CD8` 细胞的 `M131T` 在 `<=100 µm` 下落入置换零分布（`100 µm`: **`+3.34 µm, p = 0.203`**；`50 µm`: **`+4.23 µm, p = 0.289`**）。
   - **`M397T` 与 `M242T` 的 `<15 µm EPCAM⁺` vs `>=15 µm` 对称报告**：在 `SPP1⁺` 均衡（`29.3%`）的 **`M397T`** 中，`200 µm` 近肿瘤巢 `<15 µm` 为 **`+7.67 µm (p = 0.001, 318格)`**，而间质带 `>=15 µm` 降至 **`+0.71 µm (p = 0.093, 370格)`**（`100 µm`: `+2.37` vs `+0.44 µm, p = 0.190`）；对称观察高 `SPP1⁺`（`89.8%`）的 **`M242T`**，`200 µm` 近肿瘤巢 `<15 µm` 为 **`+3.09 µm (p = 0.045, 21格)`**，而间质带 `>=15 µm` 仍为 **`+4.45 µm (p = 0.001, 253格)`**（`100 µm`: `+2.28 µm [24格]` vs `+2.61 µm [333格]`），显示两例可评估患者在巢缘与间质分层上存在相反的相对幅度而非普遍消退。
   - **半格平移（`+25 µm` / `0.5 × tile`）与 `~EPCAM` 溢出限制**：原点平移 `+25 µm` 在 `50 µm` 细格下给出一致估计（`M242T` `+1.50 µm (p=0.001)`、`M397T` `+1.00 µm (p=0.001)`；`200 µm` 半格 `+100 µm` 平移：`M242T` `+4.03 µm (p=0.001)`、`M397T` `+4.86 µm (p=0.001)`，见 [半格平移敏感性](spatial_measurement_audit/grid_shift_sensitivity.csv)）；同时须注意 `~EPCAM` 门控会把紧贴高密度 `EPCAM⁺` 肿瘤巢边缘（`<15 µm`）且捕获到溢出 `EPCAM` 转录本的真实髓系细胞一并剔除（压缩近巢有效格数如 `M242T` 21 格），且缺乏配对 H&E 坏死标注。唯一邻近肝切片 `M131N` 仅 `1.1%` 髓系为 `SPP1⁺`（2–12 格），无稳定方向。[多尺度结果详情](spatial_measurement_audit/results.md) · [完整距离与置换表](spatial_measurement_audit/local_distances.csv)
