# M4 开发集模型比较约定

外层使用 M0 已保存的 5 个患者折。组织分类只使用 GSE245552 的 PT 和 LM 标本。每个 GSM 的 T/NK、Mono/Mac/DC、B/Plasma 分别建袋，按 M2 规则保留至少 50 个合格细胞的袋。同一谱系内各主比较使用相同 GSM 与同一批细胞。每袋至多 256 个细胞，按完整 cell_uid 排序后固定种子不放回抽样。全体细胞用于 M3 的生物学估计。

固定程序采用 M3 事先选定的完整文献定义。程序均值和同一袋内的可信亚型组成分别拟合 Elastic Net logistic 基线。技术对照仅用可见计数与基因数的分布。所有线性特征的标准化仅拟合训练患者。固定 C=1、l1_ratio=0.5；样本权重在患者、组织与病灶逐层等分。

PCA 入口在可见整数上做逐细胞万分归一化和 log1p。每个谱系每折只在训练细胞上选方差最高的 512 个基因，拟合中心化 32 维 PCA。scGPT 采用 whole-human 的冻结参数、词表、51 个分箱、包含 CLS 的最大 1200 个 token。由全局种子和 cell_uid 决定同值分箱与截断抽样，每个细胞保存词表覆盖。用代表细胞检验不同批次组合下的数值一致性，再决定批大小和设备。

PCA 和 scGPT 分别使用 starter 的 mean 与透明线性 attention 池化。主损失为病人等权 BCE 加 0.1 倍患者内排序，L2=0.01；无配对项为预定消融。优化参数与迭代预算固定；外层结果不用于选择参数。袋内亚型等比例的比较只使用有共同支持的亚型，并报告覆盖损失。OOF 聚合先技术样本、再病灶等权；列出 AUROC、average precision、阈值 0.5 的 balanced accuracy，以及完整配对患者的方向和差值。模型差值按共同患者重抽样。报告 attention 与带符号贡献、移除高贡献细胞和同型同数随机移除的差。

先完成程序、组成和 PCA，再评估冻结 scGPT 与直接前作的增量。每种模型记录参数、实际合格率、失败与资源。模型名区分 starter 的线性 attention 与原作者软件。
