# GSE178318 前瞻性零表达暴露次要外部验证报告（V1.1 `CRLM_V1.1_245_F1`）

在 M5 原子锁定（`CRLM_V1.1_245_F1`，`2026-11-21T17:49:04+00:00`）及完整三版本代码归档提交（Git commit `5b01467`）后，用户正式取得 Che et al. (*Cell Discovery* 2021, DOI `10.1038/s41421-021-00312-y`) 原始单细胞 UMI 矩阵使用授权。本项目在 **0 字节修改** 任何预冻结候选定义、对照箱（`matched_controls.csv`）、评分代码（`program_scores.py`）、层级注释规则（`annotation_m1.py`）与 M4 分类头的前提下，完成了 `GSE178318` 的**前瞻性零前序表达矩阵暴露验证**（冻结前仅审阅公开论文与 GEO 样本/条形码元数据；跨队列［含同属广州中山大学体系不同院区的 `245` 与 `178`］供者级非重叠状态按 `AGENTS.md` 保持 `unproven`）。

两项预登记次要检验（`SECONDARY_DT_178_V1_1`；注：`N = 6` 双检验 Holm 家族最小可能双侧符号 $p = 2/2^6 = 0.03125 > 0.025$，设计角色按 `AGENTS.md` 第 6 节为次要方向与精度支持）在全部 **N = 6** 位同步切除 IV 期 MSS 结直肠癌肝转移配对患者中**均值与非零患者多数方向 100% 符合预登记方向（2 / 2 `matches_registered_direction`）**：
- `Mono/Mac/DC::Core_Lipid_SAM_R`：宽谱系 `D_T = +0.09936`（**5 正 / 1 负**，95% CI `[+0.02024, +0.19206]`，双侧精确 `p = 0.21875`，Holm `p = 0.43750`），在其预登记焦点细类纯 `Macrophage` 内 `D_T = +0.10183`（**5 正 / 1 负**，`[+0.02595, +0.19140]`）；肿瘤核内库普弗标记对照 `Resident_Kupffer` 为 `−0.01631`（`3 正 / 3 负`，`p = 1.00000`），提示肿瘤病灶内并非由典型库普弗标记同步上调驱动（但因 `GSE178318` 无配对邻近正常肝 `NL`，器官背景交互仍以 `GSE164522` 四组织 `Q` 子集为准，不单独声称排除肝实质本底）。
- `T/NK::B07_Th17_TWEAK`：宽谱系 `D_T = −0.00986`（**2 正 / 4 负**，95% CI `[−0.02658, +0.00663]`，`p = 0.68750`，Holm `p = 0.68750`）；在其预登记焦点细类纯 **`CD4 T cell` 内强化至 `D_T = −0.02067`（1 正 / 5 负，`[−0.04040, −0.00169]`，`p = 0.21875`）**，而 `CD8 T cell` 为 `+0.00499`（`3 正 / 3 负`），在前瞻性外部队列中复现了发现集与 `GSE164522` 观察到的“纯 CD4 下调被肝内 CXCR6+ CD8 稀释”现象。[访问状态](access_status.md) · [登记检验结果](registered_tests/registered_results.csv)

## 3. 多重 QC 门槛、双尺度与环境基因剥离敏感性

在 [敏感性汇总表](patient_effects/sensitivity_summary.csv) 的全部 16 种预定义切面下，两项主候选均值方向 100% 保持一致；其中 **全部 `14/16` 个去偏切面（`ucell_debiased` 与 `log1p_cp10k_debiased`）的患者符号计数严格锁定为 `5/1` 与 `2/4`**，而 2 个未去偏排序基线（`ucell_raw` 与 `legacy_positive`）使 `Core_Lipid_SAM_R` 偏移至 `6/0`（`+0.10805`）、`B07_Th17_TWEAK` 退化为 `3/3`（`−0.00606, p = 1.0`），从反面印证检测率匹配去偏对消除稀疏度混杂的必要性：
- **原文献 B03 严格阈值（`author_b03_500g_15mt`：单纯 `n_genes >= 500 & pct_mt <= 15%` 为 `99,403` 个细胞，叠加 M2 高基因多联体门后保留 `99,375` 个肿瘤文库细胞）**：`Core_Lipid_SAM_R` `D_T = +0.09469`（`5/1`），`B07_Th17_TWEAK` `D_T = −0.01010`（`2/4`）。
- **对齐 `GSE164522` 的高基因数门槛（`min_genes_800_align164`：`n_genes >= 800`）**：`Core_Lipid_SAM_R` `D_T = +0.08772`（`5/1`），`B07_Th17_TWEAK` `D_T = −0.01474`（`2/4`）。
- **连续线性共同核标定（`log1p_cp10k_debiased`）**：`Core_Lipid_SAM_R` `D_T = +0.39865`（`5/1`），`B07_Th17_TWEAK` `D_T = −0.03228`（`2/4`）。
- **固定 `18,733` 共同核背景剥离肝细胞/红细胞环境基因与 `HLA-DRB3/4/5`（`drop_liver_Hb_DRB345`，完整保留 `HLA-DRB1`）**：`Core_Lipid_SAM_R` `D_T = +0.10103`（`5/1`），`B07_Th17_TWEAK` `D_T = −0.00901`（`2/4`）。
