# 方法学局限、审计整改记录与方案偏差说明（`CRLM_V1.1_AUDIT_REMEDIATED`）

## 1. 相对研究计划（`docs/CRLM_Research_Plan.md`）的受控工程实现调整

1. **配对伪批量负二项检验实现（Python 替代 R `edgeR`）**：
   - 原计划第 7.2 节建议优先采用 `edgeR::glmQLFTest` 准似然 $F$ 检验；鉴于本地工作流统一运行于隔离 Python 环境，本研究在 `scripts/analyze_paired_counts.py` 中采用 `PyDESeq2` 拟合 `~ donor_uid + tissue` 配对负二项 GLM（关闭 `N=2/donor` 下失真的 Cook's 距离过滤，严格屏蔽任一未收敛标志基因），升级为**有限样本残差自由度 `df = N_pairs - 1` 双侧 Student-$t$ 检验**，并在零假设满足供者内条件标签可交换性（conditional within-donor exchangeability）前提下同步输出精确遍历全部 $2^{N_{\text{pairs}}}$（`64–4,096` 种）供者内 `PT/LM` 符号翻转的精确检验（`pvalue_signflip`）。在无信号谱系 `B/Plasma` 与纯 `plasma cell` 上两种方法均给出 `0` 个 `BH < 0.05` 基因（彻底清除渐近正态的 `42` 与 `39` 个假阳性），在髓系（`661` vs `611`）与纯巨噬（`400` vs `399`）上高度一致。[配对计数汇总](../m3/paired_counts/fit_summary.csv)
2. **Intel Arc A750 XPU 硬件后端与确定性边界**：
   - 采用隔离 `.venv-scgpt`（**`torch 2.15.0+xpu`**）在 `72` 个真实三谱系肿瘤细胞上完成与 CPU `float32` 的逐细胞对位核验：最小余弦相似度 **`0.99999982`**、最大逐维绝对误差 **`2.09 × 10⁻⁷`**，跨批大小逆序重排最大绝对误差 **`8.94 × 10⁻⁸`**（[scgpt_profile.json](../m4/resource_profiles/scgpt_profile.json)），在此基础上完成开发集 `70,628` 个、`GSE164522` `68,050` 个与前瞻队列 `GSE178318` `59,338` 个编码细胞（其中 `34` 个 `>=50` 细胞合格袋入袋 `59,298` 个细胞，另含真实三版本历史 `<=256` 子袋 `7,616` 个细胞的独立 XPU 编码）。超过 `1,199` 表达基因的细胞按 `cell_uid` SHA256 独立种子抽样，完全与批次或顺序无关。

## 2. 三版本演进中已查明并闭环修复的核心缺陷记录

1. **单细胞程序评分深度偏倚修复**：初版自定义 `positive_midrank_1500` 在稀疏 scRNA-seq 下受检出基因数强混杂（合成零效应 Poisson 检验 `max |ρ| = 0.892`）。`V1.1` 升级为全测量轴 Mann–Whitney `UCell` 减去开发集锁定的 **20 桶 × 10 重复检测率匹配对照**（`debiased_ucell_scores`，合成检验 `max |ρ| = 0.0755 < 0.08`），所有外部队列（`164`、`178`、`203608`）均严格零改动复用 `artifacts/m5/matched_controls.csv`。
2. **跨队列 HGNC 基因轴与共享核空间对齐**：通过官方 HGNC 快照（含基于 `ENSG` 的重名符号 `SEPT7/SEPTIN7` 单射消歧）构建 `245_164_shared_nuclear`（`18,815` 核基因）与 `245_164_203608_shared_nuclear`（`18,733` 核基因，同样 `100%` 覆盖 `GSE178318`），显式剥离 `GSE245552` 肿瘤缺失的 `353` 个偏倚特征，使 `GSE164522` 与 `GSE178318` 全部 `15/15` 迁移模型的 `512` 维 PCA HVG 覆盖均达 **`100.0%`（零拒判）**。
3. **两阶段无冲突层级注释与跨队列细胞隔离清洗**：解耦 `CSF3R + S100A8/A9`（`FCGR3B=0`）单核/巨噬误判并补齐 `CD4/CD8` 拆分使已解析免疫谱系内部细类 `unresolved = 0.00%`；同步剔除 `GSE164522` 全部 `6,836` 个跨谱系 `CD3E+` 双细胞（含次要 `rule_annotation_m1` 分支中 140 个残留双细胞的求交剥离）、`GSE203608` 的 `12,136` 个死细胞/未注释细胞，以及物理隔离 `GSE178318` 的 `3` 份外周血 `PBMC` 文库（`26,950` 细胞）。
4. **先验 MIL 实现与评估去偏**：本地锁定 `MixMIL` 与 `hier-mil` 源码，修复 `MixedMIL` 奇偶切片 `[::2]` 丢袋与漏除 `1/sqrt(Q)` 方差膨胀，将 `HierarchicalMIL` 升级为折内 3 折供者分层内层 CV 调参，并以全袋评估 + 200 次患者置换零分布替代初版单次 256 细胞截断与偏倚哈希压力测试。

## 3. 固有科学边界与已逐项量化的微小技术边界

- **外部暴露层级与跨队列供者独立性边界**：`GSE164522` 与 `GSE203608` 因初版已读取表达值，严格定位为暴露后稳健性重评估；**`GSE178318`（`N = 6` 对）具有零前序表达矩阵/效应暴露**（冻结前仅审阅公开论文与 GEO 样本/条形码元数据，原始表达矩阵在 `5b01467` 提交后首次解锁；审计日志见 [external_exposure_master_log.csv](../m0/external_exposure_master_log.csv) 与 [external_access_log.csv](../m6/GSE178318/external_access_log.csv)）。各公开队列（广州中山大学附一院 `245`、广州中山大学孙逸仙纪念医院 `178`［同城同校不同院区］、北京大学肿瘤医院/北京世纪坛医院 `164`、美国宾夕法尼亚大学医院 UPenn `203608`、澳大利亚 Garvan/Westmead `335552`；溯源见 `starter/evidence/cohort_provenance_audit.csv`）未经基因型跨库去重，匿名供者级非重叠状态按 `AGENTS.md` 保持 **`unproven`**；`GSE225857` 因缺供者配对映射继续排除。
- **小样本离散功效、多重比较族界定与临床异质性边界**：独立推断单位严格为真实患者 `donor_uid`。4 个独立预登记家族每族 `α = 0.05` 不等于全研究共同错误率（study-wide FWER）为 `0.05`。尤其在 `GSE178318`（`N = 6` 对无平局双检验 Holm 家族）中，最小可能双侧精确符号 $p = 2/2^6 = 0.03125 > 0.025$（2 项 Holm 首阈值），数学上不可能越过族内 `0.05`，故按 `AGENTS.md` 第 6 节在设计上严格承担预定方向与精度支持。`GSE178318` 含 `3` 例未治疗与 `3` 例术前化疗患者（仅作描述性分层展示，不作治疗因果推断）；`GSE203608` 的 `Patient 49` 分期注释差异已单列剔除敏感性。
- **已独立核查存档的七项细微技术边界（`a–g`）**：
  - **(a) `18,815` 训练核轴 vs `18,733` `178/203608` 三队列共同核轴**：相差的 `82` 个非共享克隆/符号在开发集细胞中位 UMI 占比为 `0.0000%`，与 `3 × 512` 维 PCA HVG 及两项主候选 **0 重叠**，且全轴 `max_rank = 1500` 下零表达截断秩同为 `1501`。
  - **(b) 冻结 HGNC `PROVENANCE.json` 快照与基因轴计数口径**：为严格保持 M5 `72/72` 密码学哈希零字节变动，`data/manifests/hgnc/PROVENANCE.json` 保留重训前审计快照；实际 `V1.1` 在 `164` 与 `178` 实现 `512/512 = 100.0%` PCA HVG 覆盖（`V1.1` 在 `203608` 同为 `512/512 = 100.0%`，初版 `V1_F1` 为 `498–502/512`），`GSE178318` 原始 `33,694` 特征经去重/清洗获 `33,658` 个唯一可测特征（`25,715` HGNC ID + `7,943` 源符号），映射至 `18,733` 共同核宇宙。
  - **(c) M4 主种子单折注意力收敛波动**：主种子 `20261121` 的 `fold = 4` 中 `T/NK` 与 `B/Plasma` `scGPT_attention` 出现局部非收敛/低于 `0.5` 波动（受冻结 M5 哈希锁约束，`artifacts/m4/stage_report.md` 保持 `5b01467` 原字节不变，在此补充披露），进一步支持优先采用稳健线性均值池化（`PCA_mean`）。
  - **(d) 层级注释高特异门控特征**：`annotation_m1.py` 第一阶段采用高特异跨谱系/上皮双联体门拦截 `Mixed`（如 `178` 中拦截 `39,149` 个细胞），并对 `cDC2` / `pDC` 采用严格双标记判据；第二阶段 `APOE` 仅影响 `1.4%–1.7%` 巨噬细胞，而不依赖 `APOE` 的粗谱系 `Mono/Mac/DC`（`245` `11/11`、`178` `5/6`）及 `164` 作者独立标签均同向，排除循环性。
  - **(e) 去偏 UCell 对照箱零碰撞分母**：全部 **`19/19` 个进入 M3 正式筛选的完整程序**（含 `Core_Lipid_SAM_R`、`B07_Th17_TWEAK`、`B19_S4_Mac_SPP1_clean`、`UPR`）同重复对照碰撞数均为 **`0`**；在 `matched_controls.csv` 全部 `26` 个程序名中，仅未纳入筛选的历史 `651` 基因集 `B06_S6_SAM` 触发极小桶回退。
  - **(f) 肝实质 `ASGR1+ASGR2` 共表达门比例**：在 M2 全队列（含邻近正常肝 `NL`）共标记 `0.31%` 细胞（肿瘤文库内部为 `0.075%`）。
  - **(g) 置换可交换性与 `scGPT` 预训练重叠状态**：M4 的 `200` 次供者级标签置换保持同供者多标本簇结构（依赖供者级标签可交换性假设）；语料审计（[scgpt_pretraining_overlap_audit.md](../m0/scgpt_pretraining_overlap_audit.md)）记录 `GSE164522`（正常肠/肝子集）与 `GSE178318`（外周血子集）相对于 CELLxGENE 快照处于 `POTENTIAL_UNSUPERVISED_EXPOSURE_UNVERIFIED` 状态（无监督预训练不含任何 `PT/LM` 组织标签，且高分类 AUROC 不替代生物机制复现）。
- **空间观测与湿实验未执行边界**：`I = D_T_Q − D_N_Q` 是观测交互项而非因果效应（`p > 0.05` 不排除器官背景）；`GSE335552` 缺配对 `PT` 切片与 H&E 坏死标注、`<15 µm EPCAM+` 分层在 `M397T` 与 `M242T` 方向相反且受边界转录本溢出制约；**当前已完成实际湿实验数为 `0`**，机制因果闭环须按 [M7 人体四组织双色原位杂交与自体髓系 CM→CD8+ T 细胞 Transwell 趋化验证方案](../m7/candidate_validation_design.md)（区分外分泌配体与 `Sun Immunity 2026 [B43]` 胞内 `SPP1–TRIM21–SOCS1` IFN-γ 负反馈）独立实施。
